# Парковка «Акжол» — новая программа (замена Parking.Api)

Одна программа на Python (только стандартная библиотека). Делает всё сама:
камеры → въезд/выезд → тариф → QR Megapay на 2-м экране → фискальный чек в ККМ → шлагбаум.

- **Запуск: ярлык «Парковка Акжол» на рабочем столе** — поднимает программу в фоне, экран оплаты на 2-м мониторе и окно оператора. Повторное нажатие просто открывает окно оператора.
- Панель оператора: `http://192.168.0.103:8100/` (с любого ПК в сети)
- Экран оплаты (2-й монитор): `http://127.0.0.1:8100/screen`
- Сайт белого списка: `http://<IP>:8101/` (отдельный порт, можно открыть в интернет)
- Telegram-бот белого списка: @whitelist1_yn_bot
- База: `parking.db` (SQLite) рядом с программой, журнал работы: `logs\app.log`

## Без интернета

Парковка работает без интернета: камеры, шлагбаумы, тариф, белый и чёрный списки, база — всё на этом ПК.
Без интернета не работают только: QR Megapay (на экране — «Оплата картой или наличными у оператора»),
облачная ККМ (чеки встают в очередь и пробиваются автоматически, когда связь вернётся),
Telegram-бот и сайт снаружи (уведомления копятся и уходят позже).

## Тариф

| Стоял | Сумма |
|---|---|
| до 15 мин включительно | 0 |
| 16 мин – 1 ч | 50 |
| 1 ч 01 мин – 2 ч | 100 |
| … каждый начатый час +50 | … |
| ровно 24 ч | 1200 |
| 24 ч 01 мин – 48 ч | 1500 |
| 48 ч 01 мин – 72 ч | 1800 |
| дальше +300 за каждые начатые сутки | |

Числа меняются в `config.json` → `tariff`. Проверить: панель → «Тариф и тест».

## Логика

**Въезд `.14`**: номер распознан → запись о въезде → шлагбаум открыт.
Если по этому номеру уже есть незакрытый въезд (выезд не зафиксировался) — старый закрывается без оплаты, в журнал пишется предупреждение.

**Выезд `.2`**: номер распознан → сразу QR на LED-экран (и на терминал, если включён `kkm.terminal_auto`) →
1. в whitelist — бесплатно, открыть;
2. нет записи о въезде, но в последние 15 мин уже оплатил/выехал — открыть;
3. нет записи о въезде вообще — на экране «Обратитесь к оператору», в панели кнопки «Выставить оплату» / «Открыть бесплатно»;
4. до 15 мин — бесплатно, открыть;
5. иначе — оплата: на экране QR Megapay + сумма. В панели оператор может принять наличные / карту / выпустить бесплатно.

**Оператор на выезде** (блок «Выезд — оплата»): номер, который прочитала камера, подставляется сам.
Если номер прочитан неверно — исправить в поле и нажать **«QR — выставить оплату»**: старый QR снимается, новый уходит на экран и терминал.
**«📷 Запросить с камеры»** — камера делает снимок и распознаёт номер заново. Если въезда нет — указать сумму.
Номер в записи о въезде тоже можно исправить: вкладка «На парковке» → «Исправить номер».

После оплаты: экран «ОПЛАЧЕНО» 15 сек с QR электронного чека, шлагбаум открыт, чек в ККМ (если ККМ недоступна — чек встаёт в очередь и пробивается позже, кнопка «Пробить» во вкладке «Оплаты»).
QR живёт 5 минут; если клиент оплатил позже — оплата всё равно засчитывается, при следующем распознавании машину выпустят.
Если камера ошиблась в одном символе номера (`01KG128ABC` вместо `01KG123ABC`) и такая машина на парковке одна — она находится.

**Белый список** — въезд `.4` открывает только номерам из списка; на общем въезде/выезде они бесплатно. `06978ATH` = `6978ATH`.
- Добавлять/удалять — **только** через Telegram-бота или сайт, логин `admin`, пароль `admin2026`
  (сменить: `python tools\set_whitelist_password.py НОВЫЙ`). В программе оператора список только для просмотра.
- Срок: «постоянный» или «на 1 месяц» (через месяц номер удаляется сам, приходит уведомление).
- Все добавления/удаления (бот и сайт) — уведомление в Telegram всем, кто вошёл в бота, и в `telegram.notify_chat_ids` (например, группа).
- Перенос старого списка из Parking.Api: `python tools\import_whitelist.py` (пока старая программа запущена).

**Чёрный список** — ведут операторы (вкладка «Чёрный список»). Такую машину шлагбаумы въезда не пропускают,
в панели красное предупреждение с кнопкой «Открыть всё равно», уведомление в Telegram.
**Whitelist выезд `.90`**: только пишет в журнал (камера открывает сама). Чтобы открывала программа — `"open_on_plate": true`.

**Смена ККМ**: открывается сама перед первым чеком, закрывается (Z-отчёт) каждый день в `kkm.close_day_time` (по умолчанию 23:59). Кнопки во вкладке «Касса»: состояние, закрыть смену, X-отчёт, копия последнего чека / Z, внесение, изъятие.

## Установка на ПК парковки (192.168.0.103)

1. Установить Python 3.8+ с python.org (галочка «Add Python to PATH»).
2. Скачать репозиторий (git clone) или скопировать папку, например в `C:\akjol_parking\akjol_new`.
3. Проверить `config.json` (см. ниже).
4. **Остановить старое**, иначе обе программы будут открывать шлагбаумы:
   - службу Parking.Api (Службы Windows → остановить и поставить «Отключена»);
   - окна «QR server», «QR screen keeper», «Whitelist exit guard»;
   - убрать `qr-display\autostart.bat` из автозагрузки (`shell:startup`).
   До остановки можно перенести whitelist: панель → Whitelist → «Импорт из Parking.Api».
5. Камера `.4`: режим открытия — только по команде (`whitelist-exit\cam_fix.bat`), и снять «постоянно открыт» (`normal_mode.bat`).
6. В `open_screen.bat` поправить `POS` — координаты 2-го монитора.
7. **`УСТАНОВКА.bat`** (один раз, спросит права администратора) — проверка Python, правила брандмауэра, ярлык «Парковка Акжол» на рабочем столе + автозапуск. Дальше — запуск одним кликом по ярлыку.
8. Чтобы сайт белого списка открывался из интернета — на роутере пробросить порт 8101 (порт 8100 наружу НЕ открывать).
9. Машины, которые уже стоят на парковке в момент перехода: добавить вручную (вкладка «На парковке» → номер и время въезда) или выпускать через «Выставить оплату».

## config.json — что проверить

| Раздел | Что |
|---|---|
| `cameras` | IP, логин/пароль камер; `role`: `enter`, `exit`, `wl_enter`, `wl_exit` |
| `megapay.status_path` | **обязательно заполнить** — см. ниже |
| `kkm.url` / `registration_number` | сейчас **тестовая** ККМ `77.220.204.134:9995`. Для боевой — заменить |
| `kkm.vat_num` / `st_num` | ставки НДС (0 = 0%, 1 = 12%) и НСП (0–4). Сейчас 0 / 0 — уточнить у бухгалтера |
| `server.panel_password` | пароль на панель (логин любой) |
| `server.allow_simulate` | после запуска поставить `false` |

### Статус оплаты Megapay

Создание QR (`/qr/united/generate/v2`) сделано по присланному curl. Метод **проверки статуса** в присланных данных не указан. Пока он не настроен, программа не видит оплату по QR сама — в панели висит красное предупреждение, оператор подтверждает кнопкой «QR оплачен».

Как настроить: взять адрес проверки статуса из старого `qr-display` (он уже умеет это делать) или у Megacom и вписать:
```json
"status_path": "/qr/united/status/{id}",   // {id} — id транзакции из ответа генерации
"status_method": "GET"
```
Проверить: `python tools\megapay_test.py` (создаёт QR на 1 сом и показывает ответ) → `python tools\megapay_test.py status <id>`.
Если Megacom может слать уведомления — адрес приёма: `http://<внешний IP>:8101/api/megapay/callback?secret=<megapay.callback_secret>` (порт 8101, без секрета не принимается).

### Проверка ККМ

`python tools\kkm_test.py` — состояние (ничего не пробивает).
`python tools\kkm_test.py receipt` — тестовый чек на 1 сом (проверено на тестовой ККМ 14.10.2026: ФД 2229).

### Терминал

`kkm.terminal_auto: true` — при выставлении оплаты программа сразу запускает оплату картой на терминале,
подключённом к ККМ (чек ККМ пробивает сама). Если клиент оплатил по QR — ожидание на терминале отменяется.
Кнопка «Карта (терминал)» в панели — если терминал отдельный и оператор подтверждает оплату вручную.

## Камеры (Dahua, HTTP порт 80)

- События: `/cgi-bin/eventManager.cgi?action=attach&codes=[TrafficJunction]`
- Открыть шлагбаум: `/cgi-bin/trafficSnap.cgi?action=openStrobe&channel=1&info.openType=Normal&info.plateNumber=...`

Оба адреса настраиваются в `camera_api`. Статус камер — цветные метки в шапке панели (зелёная = поток событий подключён).

## Тесты

`python -m unittest tests.test_all` — тариф, номера, сценарии въезда/выезда/оплаты/чеков, разбор потока камеры.
