# Парковка «Акжол» — инструкция для Claude

Этот файл — всё, что нужно знать о программе. Читай его целиком перед любой работой.
Пользователь (Азиз) пишет по-русски, отвечай по-русски, коротко и понятно, без жаргона.

Программа написана на Mac 14–17.10.2026 и заменяет старую систему (Parking.Api + ParkingWPF + qr-display + whitelist-exit).
На Mac проверено всё, что можно без камер и терминала (см. «Что проверено»). На ПК парковки осталось:
подключить терминал, проверку оплаты Megapay, проверить камеры и переключиться со старой программы (см. «Задачи на месте»).

---

## 1. Что это

Одна программа на Python 3.8+ (только стандартная библиотека, ничего ставить через pip не нужно).
Работает на ПК парковки **192.168.0.103** (Windows). Запуск — ярлык «Парковка Акжол» на рабочем столе.

| Что | Адрес |
|---|---|
| Панель оператора | `http://192.168.0.103:8100/` (только локальная сеть, порт 8100 наружу НЕ открывать) |
| Экран оплаты (2-й монитор, квадратный LED) | `http://127.0.0.1:8100/screen` |
| Сайт белого списка (можно открыть в интернет — проброс порта 8101 на роутере) | `http://<IP>:8101/` |
| Telegram-бот белого списка | @whitelist1_yn_bot |
| База | `parking.db` (SQLite) рядом с программой |
| Журнал | `logs\app.log` + вкладка «Журнал» в панели |

## 3. Правила (не нарушать)

1. **Тесты** `python -m unittest tests.test_all` должны проходить после любой правки.
2. **Тестовые чеки — только на тестовой ККМ.** На боевой каждый чек — настоящая продажа.
3. **Скрытый белый список** (`whitelist2.txt`) нигде не показывать: ни в панели, ни в журнале, ни в Telegram, ни в README.
   Машины из него проезжают молча (`quiet=True`, обработчики возвращают `False`, камера не запоминает их номер).
   Есть тест `test_hidden_leaves_no_trace_anywhere`.
4. **Основной белый список** меняется только через бота и сайт (логин/пароль). В панели оператора — только просмотр.
5. Порт **8100 не открывать в интернет** (панель без пароля может открыть шлагбаум). Наружу — только 8101.
6. Перед тем как менять что-то на работающей парковке — спроси пользователя. Откат — раздел 9.

## 4. Тариф

- до 15 мин включительно — 0;
- далее 50 сом за каждый начатый час: 15:00→15:16 = 50, →16:00 = 50, →16:01 = 100;
- 24 ч = 1200; после — 1200 + 300 за каждые начатые сутки (24 ч 01 мин = 1500, 48 ч 01 мин = 1800);
- считается по **целым минутам** (секунды отбрасываются — как видит клиент на экране).
Настройки: `config.json → tariff`.

## 5. Как работает

**Въезд .14 (общий):** номер → запись о въезде → открыть. Чёрный список — не открывать, красное предупреждение в панели + Telegram.
Повторное распознавание в течение 2 мин — просто открыть. Новый въезд при незакрытом старом — старый закрывается без оплаты (в журнал).

**Выезд .2 (общий, платный):**
1. белый список — бесплатно, открыть;
2. уже оплатил/выехал за последние 15 мин — открыть;
3. нет записи о въезде — экран «Обратитесь к оператору», в панели номер подставлен, оператор указывает сумму → «QR»;
4. ≤15 мин — бесплатно, открыть;
5. иначе — счёт: QR Megapay на LED (+ терминал, когда будет подключён). Оплата → «ОПЛАЧЕНО» 15 сек с QR электронного чека → открыть → чек в ККМ.
- Оператор может исправить номер и нажать «QR — выставить оплату» (старый счёт отменяется), «📷 Запросить с камеры», «Наличные», «Карта (терминал)», «QR оплачен», «Выпустить бесплатно».
- Если клиент оплатил старый QR той же машины — засчитывается, новый снимается (нет двойной оплаты).
- QR живёт 5 мин; оплата после истечения засчитывается, и если машина всё ещё у шлагбаума — открывается.
- Чёрный список на выезде: выпуск только после оплаты + предупреждение.

**Whitelist въезд .4:** открывает только номерам из белого списка (основного или скрытого). Чёрный список важнее основного белого.
**Whitelist выезд .90:** камера открывает сама (AllSnapCar); программа только пишет в журнал. `open_on_plate: true` — открывать программой.

**Белые списки:**
- основной — бот/сайт, логин `admin`, пароль `admin2026` (хеш в `config.json → whitelist.admin_password_sha256`);
  категории «постоянный» и «на 1 месяц» (через календарный месяц удаляется сам + уведомление);
  каждое добавление/удаление/истечение — уведомление в Telegram всем, кто вошёл в бота (+ `telegram.notify_chat_ids`);
  смена пароля (`tools/set_whitelist_password.py`) выкидывает всех из бота.
- скрытый — файл `whitelist2.txt` рядом с программой, один номер на строку, постоянные; перечитывается на лету; UTF-8 или ANSI.

**Чёрный список:** ведут операторы во вкладке «Чёрный список».

**Без интернета:** работает всё, кроме QR Megapay (на экране «картой или наличными у оператора»), облачной ККМ
(чеки в очереди, пробиваются сами, когда связь вернётся, без лимита попыток) и Telegram (уведомления в очереди в базе).

**Чеки:** cacheId `akjol-pay-<id>-<n>`: при обрыве связи повтор с тем же id (ККМ вернёт прошлый результат, не задвоит),
при ошибке от ККМ n+1. Карта через ККМ: `akjol-card-...`, при обрыве — тот же id и предупреждение оператору.
Смена: открывается сама перед первым чеком, закрывается в `kkm.close_day_time` (23:59) и если истекла.

## 6. Проверенные факты

- **ККМ тестовая** `http://77.220.204.134:9995`, РНМ `0000000000024532` (облачная, CLOUD; регистрация чужая тестовая — «Осоо Бизнес Ланч»).
  Чеки проходят: ФД 2229, 2234, 2235. Ответ: `{"status":0,"fdNumber":...,"qrCode":"http://92.62.72.170:30105/tax-web-control/...","shiftNumber":259}`.
  API: POST `/fiscal/<group>/<method>/` с JSON, в каждом запросе `registrationNumber`. Документация: https://documenter.getpostman.com/view/8816590/UzXLyxTd
- **Megapay** `https://app1.megacom.kg:9090/site-api`, Basic `karavella_qr`, serviceId 6533 (сервис «MP IHntihmak Dostuk – KPP Ak-zhol parkovka»).
  POST `/qr/united/generate/v2` → `{"data":"https://megapay.kg/get#000201...","qrTransactionId":"<32 hex>","status":"SUCCESS"}`.
  `paymentAmount` — в **сомах** (в QR 100 сом = тег 54 `10000` тыйын). Верхний `"status"` — статус запроса, НЕ оплаты.
  **Проверка статуса оплаты не найдена**: `/qr/united/status/{id}` и др. — 404; `/qr/status/{число}` существует
  (`{"status":"FAIL","message":"payment not found"}`), но принимает числовой id, а не qrTransactionId.
- **Камеры**: клиент проверен на имитации Dahua с digest-авторизацией (события, openStrobe, manSnap). На реальных — нет.
- **Telegram-бот** @whitelist1_yn_bot — токен рабочий.

## 7. Задачи на месте (по порядку)

1. **Изучить старый `C:\akjol_parking\akjol_parking\qr-display`** (QR-сервер, Python; там `config.json`, `pos_log.txt`, `/debug`):
   - **терминал 192.168.0.112:8090** — как QR-сервер отправляет сумму на терминал и узнаёт итог (старый Parking.Api слал оплату на `PosIp`,
     ждал `success`/`fail`; QR-сервер был посредником). Сделать `parking/terminal.py` и запускать его в `_start_terminal`
     вместо/вместе с вариантом через ККМ; при оплате QR — отменять ожидание на терминале (раньше QR-сервер «снимал ожидание»).
     Пользователь выбрал: терминал «как раньше», через 192.168.0.112:8090.
   - **статус оплаты Megapay** — как QR-сервер понимал, что QR оплачен. Вписать в `megapay.status_path` (+ `status_method`,
     при необходимости `status_key`). ОБЯЗАТЕЛЬНО проверить на НЕоплаченном QR (`tools/megapay_test.py`, потом `status <id>`),
     что он НЕ определяется как оплаченный (иначе шлагбаум будет открываться бесплатно).
2. **Камеры**: `whitelist-exit\` (cam_check.bat, test_open.bat, whitelist_exit.py) уже работали с камерами по HTTP —
   сверить команды с `camera_api` в config.json. Проверить на месте: в панели метки камер зелёные, номер приходит, «Открыть» открывает.
   Камера .4 — режим «только по команде» (`whitelist-exit\cam_fix.bat`) и выключить «постоянно открыт» (`normal_mode.bat`).
3. **Переключение со старой программы** (с пользователем, в тихое время):
   - перенести белый список: `python tools\import_whitelist.py` (пока Parking.Api запущен);
   - остановить и отключить службу Parking.Api, закрыть окна «QR server», «QR screen keeper», «Whitelist exit guard»,
     убрать `qr-display\autostart.bat` из `shell:startup`;
   - `УСТАНОВКА.bat` → ярлык «Парковка Акжол»; в `open_screen.bat` поправить `POS` под 2-й монитор;
   - машины, уже стоящие на парковке: «На парковке» → добавить вручную со временем въезда (или выпускать через «QR» с суммой).
4. **Боевая ККМ**: заменить `kkm.url` и `kkm.registration_number`; `python tools\kkm_test.py` (без receipt) — проверка связи.
   Ставки `kkm.vat_num` (0=0%, 1=12%) и `kkm.st_num` (НСП 0–4) — уточнить у бухгалтера (сейчас 0/0).
5. **Безопасность**: задать `server.panel_password`; пароль бота/сайта `admin2026` слабый — предложить сменить;
   сайт 8101 работает по HTTP (без шифрования).
6. Уведомления Megapay (если Megacom умеет): адрес `http://<внешний IP>:8101/api/megapay/callback?secret=<megapay.callback_secret>`.
   Пока `callback_secret` пустой — приём выключен.

## 8. Тестовый режим

`config.test.json` (камеры `enabled:false` — шлагбаумы только в журнал, сеть не трогается; база `test.db`):
`python app.py config.test.json`. Номера вводятся в панели: «Тариф и тест» → «Как будто камера распознала»
(работает только при `server.allow_simulate: true`; в боевом config.json — false).

## 9. Откат на старую систему

Закрыть новую программу (диспетчер задач → python), включить службу Parking.Api (`server_publish\install_service.bat`),
запустить `qr-display\autostart.bat`. Старая система не удалялась. Её описание — раздел 10.
